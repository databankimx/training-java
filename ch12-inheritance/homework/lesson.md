## Homework

These exercises build class hierarchies with an abstract parent, each subclass supplying its own part. Each one is a step in this folder.

The steps are:

* [Shape perimeters](#goto/01-shape-perimeters): an abstract `Shape` with an abstract `perimeter` method, and two concrete shapes.
* [Payroll](#goto/02-payroll): an abstract `Employee` whose pay is calculated differently by each subclass.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
