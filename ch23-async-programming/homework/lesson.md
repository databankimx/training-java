## Homework

These exercises practise running work in the background and gathering the results. Each one is a step in this folder.

The steps are:

* [Parallel squares](#goto/01-parallel-squares): squares computed by separate futures, then added together once all are ready.
* [Safe fallback](#goto/02-safe-fallback): a failing background read given a fallback value, so the program continues.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
