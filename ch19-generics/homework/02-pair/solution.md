## Homework: Pair: walkthrough

The class has two type parameters, `First` and `Second`, and each field and method uses the type that fits it. A `Pair<Integer, String>` returns an `Integer` from `getFirst`, and a `Pair<String, Double>` returns a `String` from `getFirst`.

The output prints each value with a space between them. The `Double` value 3.14 prints as `3.14`, since its decimal form is exact enough for that display.
