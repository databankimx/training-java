## Homework

These exercises use generics for a method that works on lists of any comparable type, and for a class that holds two values of different types. Each one is a step in this folder.

The steps are:

* [Smallest of](#goto/01-smallest-of): a generic method that returns the smallest value in a list, used for numbers and for words.
* [Pair](#goto/02-pair): a generic class with two type parameters, used with two combinations of types.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
