## Homework

These exercises build small windows with a label, buttons, and listeners. Each one is a step in this folder.

The steps are:

* [On and off button](#goto/01-on-off-button): a button that switches a label between `On` and `Off`.
* [Reset counter](#goto/02-reset-counter): a counter with an add button and a reset button.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
