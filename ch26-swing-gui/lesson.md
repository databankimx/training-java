## Ch26 · Swing windows

A graphical program puts its work in windows, with buttons and text that the user can click and read. Swing is Java's standard library for these windows, and it comes with the JDK. This chapter covers opening a window, responding to clicks with listeners, and arranging components with layouts.

The steps are:

* [Your first window](#goto/01-first-window): a window with a label, built on the event dispatch thread.
* [Buttons and events](#goto/02-buttons-and-events): a button whose click updates a label.
* [Layouts](#goto/03-layout): arranging components with BorderLayout, GridLayout, and panels.
* [Summary](#goto/04-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.

---

*The examples and explanations are new. A graphical program runs until its window is closed, so the Run button shows Stop while the window is open.*
