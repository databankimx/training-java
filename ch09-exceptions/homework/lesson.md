## Homework

These exercises practise exceptions in input and file handling. Each one is a step in this folder.

The steps are:

* [Safe age](#goto/03-safe-age): asking for an age until a valid one is given, recovering from bad input with exceptions.
* [Required file](#goto/04-required-file): a method that reads a file the program needs, and reports a failure to `main`.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
