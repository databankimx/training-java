## Ch04 · Arrays

Until now, each value has had its own variable. This chapter introduces the array, which stores a list of values of one type under a single name. You'll learn how to create an array, how to refer to each element by its index, and the ways to fill one when you create it.

The steps are:

* [Declaring arrays](#goto/01-declaring-arrays): creating an array, indexing from zero, and what happens when an index is past the end.
* [Initializing arrays](#goto/02-initializing-arrays): filling an array when you create it, default values, and finding the length.
* [Multidimensional arrays](#goto/03-multidimensional-arrays): grids with a row and a column index, and how to create them.
* [Summary](#goto/04-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
