## Homework

These exercises apply the search and sort ideas from this chapter: counting the out-of-order pairs in a list, and writing the first-position search that the library doesn't provide. Each one is a step in this folder.

The steps are:

* [Count inversions](#goto/01-count-inversions): counting out-of-order pairs, and checking the count against the moves insertion sort makes.
* [Lower bound](#goto/02-lower-bound): binary search for the first position that is not smaller than a target, on a list with repeated values.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
