## Homework

These exercises practise writing and reading files. Each one is a step in this folder.

The steps are:

* [Save and load scores](#goto/01-save-and-load-scores): write a list of scores to a file, then read them back and add them up.
* [Visit log](#goto/02-visit-log): add a line to a log file each time the program runs, and show the whole log.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
