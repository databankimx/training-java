## Ch07 · Methods

Up to now, every program has been one `main` method. This chapter splits a program into named methods, so each piece has a job, and the same job can be used from several places. You'll learn how to define a method and call it, how values go in through parameters and come out through return values, how arrays are passed, how a method can work on a caller's object, and how a method can call itself.

The steps are:

* [Defining methods](#goto/01-defining-methods): defining and calling a method, and where it can be placed in the file.
* [Parameters](#goto/02-parameters): passing arguments, and how a value is copied into a parameter.
* [Return values and overloading](#goto/03-return-values): sending a result back, and giving one name to several methods.
* [Arrays as parameters](#goto/04-arrays-as-parameters): passing an array, and why its length is never passed separately.
* [References as parameters](#goto/05-references-as-parameters): what a method can change in its caller's data, and what it can't.
* [Recursion](#goto/06-recursion): a method that calls itself.
* [Summary](#goto/07-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
