## Ch07 · Methods

Up to now, every program has been one `main` method. This chapter divides a program into named methods, so each piece has a job and the same job can be used from several places. You'll learn how to define and call a method, how values go in through parameters and come out through return values, how arrays and references are passed, and how a method can call itself.

The steps are:

* [Defining methods](#goto/01-defining-methods): defining and calling a method, and why Java needs no declaration before use.
* [Parameters](#goto/02-parameters): passing arguments, and the overloads that replace default values.
* [Return values and overloading](#goto/03-return-values): sending a result back, and giving one name to several methods.
* [Arrays as parameters](#goto/04-arrays-as-parameters): passing an array, and what the method can learn about it.
* [Reference parameters](#goto/05-reference-parameters): letting a method change its caller's data.
* [Recursion](#goto/06-recursion): a method that calls itself, traversing a folder tree.
* [Summary](#goto/07-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
