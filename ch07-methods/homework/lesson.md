## Homework

These exercises use methods in the ways this chapter showed: overloading for related calculations, and array parameters for a search. Each one is a step in this folder.

The steps are:

* [Area calculator](#goto/01-area-calculator): overloaded `area` methods for a circle and a rectangle.
* [Largest value](#goto/02-largest-value): a method that takes an array and returns its largest element.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
