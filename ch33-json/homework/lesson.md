## Homework

This exercise uses the JSON library to read a set of settings, change them, and write them back out.

The steps are:

* [Settings round trip](#goto/01-settings-round-trip): reading saved settings, changing two values, and writing them back.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
