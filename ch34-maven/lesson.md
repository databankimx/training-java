## Ch34 · Maven

Maven is the build tool most Java projects use. It compiles the code, runs the tests, manages the libraries a project depends on, and packages the result as a jar file. This chapter covers the standard project layout, the `pom.xml` file that describes a project, and the commands that build it.

The steps are:

* [Project layout](#goto/01-project-layout): where Maven expects the source, the tests, and the build output.
* [The pom.xml file](#goto/02-pom-file): identifying a project, its Java version, and its dependencies.
* [Building and packaging](#goto/03-build-and-package): the build commands, and running the packaged jar.
* [Summary](#goto/04-summary): a recap of the chapter and a short quiz.

---

*The examples and explanations are new. Maven runs in a terminal outside the course runner, so its commands are shown as reference text, and the runner runs the programs.*
