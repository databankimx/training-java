## Ch25 · Modern features

Recent Java releases added features that cut repetition from code and make its intent clearer. This chapter covers the ones used most often in everyday code: `var`, which lets the compiler work out a type from its value, record patterns and `switch` expressions, which test the shape of a value and name its parts, and `Optional`, which states that a result may be missing.

The steps are:

* [var and patterns](#goto/01-var-and-patterns): letting the compiler work out types, and matching records and types in one step.
* [Optional](#goto/02-optional): returning a value or nothing, and reading it safely.
* [Summary](#goto/03-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
