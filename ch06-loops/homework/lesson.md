## Homework

These exercises practise the loops from this chapter, with nested loops for a table and `break` for a search. Each one is a step in this folder.

The steps are:

* [Times table](#goto/01-times-table): a nested loop that prints a multiplication table.
* [Find the first match](#goto/02-find-first-match): a loop over an array that stops at the first value that matches.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
