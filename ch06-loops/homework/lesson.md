## Homework

These exercises practise the loops from this chapter: counting down, and printing a table. Each one is a step in this folder.

The steps are:

* [Countdown](#goto/03-countdown): a `for` loop that counts down from a number the user enters, then announces the launch.
* [Times table](#goto/04-times-table): a `for` loop that prints the multiplication table for a number the user enters.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
