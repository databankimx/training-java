## Homework

These exercises split a program across files, with each class in a file of its own. Each one is a step in this folder.

The steps are:

* [Library](#goto/03-library): a `Book` class, a `Library` class, and a `Main` class in separate files.
* [Temperature utilities](#goto/04-temperature-utils): a class with two conversion methods, used from `Main`.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
