## Ch13 · Headers and multiple files

A program grows, and its classes need to be organized across files. This chapter covers how a class is split between a declaration and its code, how a file names the classes it uses from elsewhere, and how several classes are combined in one program, with one class built from others.

The steps are:

* [Interfaces and classes in separate files](#goto/02-interface-and-class): declaring what a class provides in an interface, and writing the code in the class file.
* [Imports and repeated names](#goto/03-imports): how a file refers to a class it uses, and what happens when a name is repeated.
* [Combining classes across files](#goto/04-combining-classes): building one class from others, across files.
* [Summary](#goto/05-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
