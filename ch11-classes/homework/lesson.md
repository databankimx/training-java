## Homework

These exercises build classes with private data and checked operations, and a constructor that sets the starting state. Each one is a step in this folder.

The steps are:

* [Bank account](#goto/03-bank-account): a class whose balance changes only through checked deposits and withdrawals.
* [Counter](#goto/04-counter): a class with two constructors, which counts up and resets.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
