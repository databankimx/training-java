## Homework

These exercises build classes with private data and checked changes, the way this chapter showed. Each one is a step in this folder.

The steps are:

* [Thermostat](#goto/01-thermostat): a class that keeps a target temperature, and refuses settings outside a safe range.
* [Shopping cart](#goto/02-shopping-cart): a class that holds prices, and reports a total.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
