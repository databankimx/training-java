## Ch11 · Classes

A record groups values, and it can't do anything else. A class groups values too, and it can also hold the methods that work on them. This chapter covers how to write a class, create objects from it, give it methods and constructors, compare and print objects, define enums and natural order, and keep its data under control.

The steps are:

* [Classes and objects](#goto/01-classes-and-objects): declaring a class with fields, and creating objects from it.
* [Methods](#goto/02-methods): functions that belong to a class, and the methods that only read.
* [Constructors](#goto/03-constructors): setting an object's fields when it's created, and passing arguments to a base class.
* [Equality and text](#goto/04-equality-and-text): `equals`, `hashCode`, and `toString`.
* [Enums](#goto/05-enums): a fixed set of named values, with data and methods.
* [Natural order and comparators](#goto/06-natural-order): `Comparable`, and sorting with a `Comparator`.
* [Access control and encapsulation](#goto/07-encapsulation): keeping fields private, and controlling how they're read and changed.
* [Summary](#goto/08-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
