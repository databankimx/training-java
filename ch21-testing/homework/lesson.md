## Homework

These exercises write a function, the checks that test it, and a test class that ends with an exit code. Each one is a step in this folder.

The steps are:

* [Leap-year tests](#goto/01-leap-year-tests): a leap-year method, with checks for the edge years 1900 and 2000.
* [Vowel tests](#goto/02-vowel-tests): a method that counts vowels in a word, with checks for an empty word and for a word with no vowels.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
