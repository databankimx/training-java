## Homework: Vowel tests: walkthrough

`countVowels` looks at each character and counts it when `"aeiou"` contains it. An empty word has no characters, so the loop never runs and the count is 0.

"education" has five vowels: e, u, a, i, and o. The `Tests` class checks the same cases and counts failures in the same way, and its exit code is 0 when all four pass.
