## Homework

These exercises put the chapter to work: variables, arithmetic, strings, and input. Each one is a step in this folder, and the exercise's lesson says what to write.

The steps are:

* [Unit converter](#goto/01-unit-converter): a program that converts a temperature from Celsius to Fahrenheit.
* [Greeting card](#goto/02-greeting-card): a program that asks for a name and an age, and prints a greeting.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
