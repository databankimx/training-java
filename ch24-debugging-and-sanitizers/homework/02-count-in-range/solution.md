## Homework: Count in range: walkthrough

The loop checks each value against both limits, and counts it only when it's between them. Because the comparisons are `>=` and `<=`, the limits themselves are counted.

For the range 2 to 4, the values 2, 3, and 4 pass, so the count is 3. For the range 1 to 5, every value passes, so the count is 5.
