## Homework

These exercises practise checking a promise with an assertion, and finding an off-by-one boundary. Each one is a step in this folder.

The steps are:

* [Checked average](#goto/01-checked-average): an average method whose caller must never pass an empty array, protected by an assertion.
* [Count in range](#goto/02-count-in-range): counting the values in a range that includes both ends.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
