## Ch05 · References

Arrays gave you a list of values under one name. This chapter covers how a program refers to an object without copying it. In Java, a variable of an object type holds a reference to the object, so several variables can refer to one object. This chapter covers references, the special value `null` for a reference that refers to nothing, and how references to arrays reach their elements.

The steps are:

* [References](#goto/01-references): several names for one object, and what changes when a name is reassigned.
* [Null](#goto/02-null): the reference value that means no object, and how to check for it before use.
* [References and arrays](#goto/03-references-and-arrays): how an array reference reaches each element, and why an array passed to a method knows its own length.
* [Summary](#goto/04-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
