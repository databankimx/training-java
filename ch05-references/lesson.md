## Ch05 · References

Arrays gave you a list of values under one name. This chapter covers how Java refers to objects, such as arrays and strings. A variable of an object type doesn't hold the object itself. It holds a reference to it, which is a way of finding the object, and several variables can hold references to the same object.

The steps are:

* [References](#goto/01-references): several names for one array, and what changes when a name is reassigned.
* [Null](#goto/02-null): the value that means no object, and how to check for it before you use it.
* [Comparing references and values](#goto/03-comparing): why `==` and `equals` give different answers for text.
* [Summary](#goto/04-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
