## Ch10 · Records

Many values belong together: a point has an x and a y, a car has a brand, a model, and a year, and a program that handles cars should handle them as one thing. Java calls a grouping of related values a record. This chapter covers how to declare one, how methods use it, and how to create one with its values set from the start.

The steps are:

* [Records as types](#goto/01-records-as-types): declaring a record, creating one, and reading its parts.
* [Records in methods](#goto/02-records-in-methods): passing a record, returning one, and why a record can't be changed.
* [Creating records](#goto/03-creating-records): the canonical constructor, checking values when a record is created, and comparing records.
* [Summary](#goto/04-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
