## Ch10 · Records

Many values belong together: a car has a brand, a model, and a year, and a program that handles cars should handle them as one thing. Java calls a grouping of related values a record. This chapter covers how to declare one, how to create it with its values set from the start, and how methods pass and return records.

The steps are:

* [Records as variables](#goto/01-records-as-variables): declaring a record, creating one, and reading its components.
* [Records in functions](#goto/02-records-in-functions): passing a record, returning one, and returning a changed copy.
* [Initializing records](#goto/03-initializing-records): constructors that set every component, and defaults supplied by extra constructors.
* [Summary](#goto/04-summary): a recap of the chapter and a short quiz. The homework is listed under the chapter.
