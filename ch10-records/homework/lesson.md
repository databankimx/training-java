## Homework

These exercises use records for groups of related values: a list of contacts, and a rectangle that can be scaled. Each one is a step in this folder.

The steps are:

* [Address book](#goto/03-address-book): an array of contact records, searched by name.
* [Rectangle scale](#goto/04-rectangle-scale): a rectangle record, with an area method and a scale method that returns a new rectangle.

Write your own program in your project first. If you get stuck, reveal the example. The source shows the finished program, and the section below says which lines to change for your own version.
